Cascadia · visual style · draft 1

Type, color and modes

Built on Broadsheet: one serif, paper ground, two spot colors. Cyan means action and payout; magenta means loss and alerts. Every Cascadia token is a role (ground, ink, payout…) that points at a Broadsheet ramp step, so light and dark mode swap the pointers and nothing else.

Font system

Source Serif 4 for everything, including UI chrome. Weights 400 and 600 only, plus the true italic for quotes. All figures use tabular lining numerals so money columns align. The investor portal steps every size up one level.
